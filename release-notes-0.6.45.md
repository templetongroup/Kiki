# Kiki 0.6.45

- Adds Signal Meter as a fourth Listening Display option alongside Full Transcript, Voice Halo, and Hidden.
- Shows microphone strength through seven compact, bottom-anchored sage bars driven by the live input signal.
- Uses a fixed-height, illumination-based meter when Reduce Motion is enabled.
- Adds restrained pointer feedback to Kiki's custom buttons, a slim sage selection rail, and a brief destination reveal to navigation.
- Keeps keyboard actions and native macOS menus immediate while using a brief state transition where explanatory copy changes.
