# Kiki 0.6.51

- Adds a real Home orientation screen with setup status, a three-step first-dictation guide, and equal-size actions for dictation, meetings, and audio import.
- Replaces the listening orb approximation with a native Metal port of OrbKit SHDR-21 Nimbus, using Templeton colors and distinct idle, thinking, and speaking motion states.
- Removes Voice Studio and local voice-cloning code, menus, assets, and MLX dependencies from the application.
- Preserves transcripts, dictionary entries, approved replacements, settings, and other existing local user data.
